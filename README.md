# Ina Marie Forseth - Portfolio 2

![Portfolio 2 homepage](/assets/portfolio-home.png)

A protfolio project for the Frontend Development course at Noroff School of Technology and Digital Media.

## Description

A small, fast portfolio site showcasing three projects from my final term at Noroff (Frontend Development). Each teaser opens an article page with a hero image, caption, and links to the live site and README.

## Highlights

✨ Highlights

- Multipage site with teaser cards → article pages (meets brief)
- Accessible navigation (visible focus states, keyboard-friendly)
- Lightweight & responsive UI (Tailwind v4, fluid cards)
- Article pages include: title, share/copy link, hero image + caption, live demo, GitHub README, and detailed write-up
- Deployed on Vercel with next-sitemap for SEO

## Getting Started

### Installing

**Prerequisites**

- Node 18+
- npm 9+

1. Clone the repo:

```bash
git clone https://github.com/Inamarie84/portfolio2.git
```

2. Install the dependencies and run:

```bash
npm install
npm run dev    # http://localhost:3000
```

3. Build and start

```bash
npm run build
npm start
```
